# Feisal Onyango — Portfolio

Personal portfolio site for Feisal Onyango, a frontend developer based in Nairobi, Kenya. Built as a single, self-contained page showcasing services, selected work, process, and contact details.

**Live site:** https://feizalsmitth.github.io/feisal-smitth/

## About

Feisal is a frontend-focused web developer with two years of experience building responsive, accessible interfaces for studios and small businesses — from marketing sites and landing pages to internal dashboards and e-commerce storefronts.

## Built with

- HTML5 & CSS3 (no framework, no build step)
- Vanilla JavaScript (typing animation, scroll-based nav highlighting)
- Google Fonts — Space Grotesk, Inter, JetBrains Mono

## Structure

- `index.html` — the entire site (markup, styles, and scripts in one file)

## Running locally

No build tools required. Clone the repo and open `index.html` directly in a browser, or serve it locally:

python3 -m http.server

Then visit http://localhost:8000.

## Deployment

Hosted on GitHub Pages, served directly from the `main` branch of this repository.
